# Numinous index page bundle

This package contains the complete one-page `index.html` landing page and every local dependency it uses:

- `index.html` — page markup
- `assets/numinous-clean.css` — complete shared styling
- `assets/site.js` — small optional progressive enhancement for the curved header and mobile menu
- `assets/` — local hero, logo, and product artwork
- `fonts/` — locally hosted display, body, and serif fonts

No build step or package manager is required. Serve this folder with any static web server, or open `index.html` directly in a browser. Product buttons use the live Whop checkout handoffs.
